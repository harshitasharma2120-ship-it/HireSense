# HireSense

HireSense is a Java-based job portal web application that connects
job seekers with employers.

## Technologies Used
- Java
- JSP/Servlets
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## Features
- User registration and login
- Job seeker profile
- Employer job posting
- Job search
- Job application
- Admin management

## Database Setup
1. Create a MySQL database named hiresense_db.
2. Execute schema.sql.
3. Configure database credentials in the application.
4. Deploy the project on Apache Tomcat.
